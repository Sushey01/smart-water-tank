\section{What was built}

One Node.js process serves home \texttt{home\_001}. Simulated sensors publish on MQTT. The API validates each reading, stores it, updates the latest value, and runs the rules. Commands return on MQTT. The status page and Telegram talk only to the API.

All three databases use the same replica set \texttt{rs0} on ports 27017, 27018, and 27019. The set is already initialised. Telemetry and \texttt{device\_latest} use write concern \texttt{w:1}. Incidents use \texttt{w:"majority"}. The rule engine reads from the primary. \texttt{smart\_water} also keeps \texttt{tanks}. Water documents still carry \texttt{tank\_id}. Every automation document carries \texttt{subsystem\_id}.

\section{Facts that stay fixed}

\begin{itemize}
\item Telemetry topic:\\
\texttt{ioThings/\{home\}/\{subsystem\}/\{device\_type\}/\{device\_id\}/telemetry}
\item Command topic: the same path ending in \texttt{/command}, at QoS~1.
\item Water devices are level, flow, pump state, and inlet presence. The inlet sensor separates a dry pump from a broken pump.
\item Litres in the tank are calculated when the tank is read. They are not stored as their own sensor message.
\item Litres saved on cutoff is flow in litres per minute times 20. The overflow scenario uses 15~L/min, so the recorded save is 300~L.
\item A multi-sensor rule runs only when the readings it needs were updated together.
\item The engine does not open a second incident for a rule that already has an open incident.
\item Telegram is sent only when the bot token is the full BotFather value and the chat id is the person's own id. The API reads \texttt{.env} only at startup.
\item A phone app, real hardware, a pet feeder, pump schedules, and starting the pump on a low tank were left out on purpose.
\end{itemize}

\section{How to run a case while writing}

From the project root, with the replica set already up: \texttt{npm run seed}, then \texttt{npm run dev}. In a second terminal run one of \texttt{npm run simulate -- overflow}, \texttt{study}, or \texttt{cool}. \texttt{cool} changes only the living room. The tank and the desk stay on their last stored readings until their own simulators run. Stop \texttt{cool} with Ctrl+C so cooling alerts do not repeat.
